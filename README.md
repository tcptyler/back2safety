# back2safety

Free tools to help you check whether an email, link, or file is safe before you trust it.

> **Status:** early development. Not ready for use yet.

## What it will do

**back2safety email check** lets you paste or upload a suspicious email and get a clear verdict: **Safe**, **Suspicious**, or **Dangerous**, with plain-language reasons.

- **Checks what matters:** sender authentication (SPF, DKIM, DMARC), lookalike and brand-new domains, hidden links, risky attachments, QR codes, and common scam tactics.
- **Cross-checks multiple sources:** findings are verified against several independent threat-intelligence services instead of trusting just one.
- **Private by design:** it runs on your own computer. Your emails stay on your machine; only links and file fingerprints (hashes) are looked up.
- **Free:** it works with free threat-intelligence services, using your own free API keys.
